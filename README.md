# UNIVERSIDAD_JAVA

Este repositorio es una recopilación de ejercicios, prácticas y proyectos desarrollados a lo largo de mi formación universitaria en Java. Incluye desde fundamentos básicos hasta aplicaciones avanzadas, abarcando tecnologías y frameworks modernos utilizados en el desarrollo full-stack.

##  Contenido

- **Java Básico**: Tipos de datos, estructuras de control, programación orientada a objetos (POO).
- **Java Intermedio**: Colecciones, manejo de excepciones, archivos, hilos.
- **Java Avanzado**: JDBC, Servlets, JSP, patrones de diseño.
- **Frameworks y Herramientas**:
    - **Hibernate**: Mapeo objeto-relacional (ORM).
    - **Spring Boot**: Desarrollo de aplicaciones y microservicios.
    - **Spring Security**: Autenticación y autorización.
- **Front-End**:
    - **React JS**: Bibliotecas para interfaces de usuario.
    - **Angular**: Framework para aplicaciones web de una sola página (SPA).
- **Bases de Datos**:
    - **MySQL**: Base de datos relacional.
    - **MongoDB**: Base de datos NoSQL.
